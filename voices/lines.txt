# Generation (pick one):
#   A) edge-tts (free, natural):
#      pip install edge-tts
#      edge-tts --voice en-US-AriaNeural --text "<line>" --write-media tmp.mp3
#      ffmpeg -i tmp.mp3 -ar 16000 -ac 1 -sample_fmt s16 voices/<name>.wav
#   B) macOS say (fastest):
#      say -v Samantha -o tmp.aiff "<line>"
#      ffmpeg -i tmp.aiff -ar 16000 -ac 1 -sample_fmt s16 voices/<name>.wav
#   C) ElevenLabs — for the final brand voice, same ffmpeg convert.
#

#   python examples/voice.py --check voices/<name>.wav
